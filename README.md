# Stock Research Workspace

แดชบอร์ดหุ้นและ ETF ภาษาไทย: https://my-stock-terminal.streamlit.app/

## การใช้งาน

พิมพ์ Ticker ในแถบซ้าย แล้วเลือกมุมมอง: ภาพรวมและค้นหา, กราฟและแผนซื้อ, พื้นฐานและปันผล, ความเสี่ยง, เปรียบเทียบหลายตัว หรือสถานะข้อมูล

หน้าเว็บแยกจำนวนรายชื่อออกจากจำนวนที่มีราคาจริง ช่องว่างคือยังไม่มีข้อมูล ไม่ใช่ศูนย์ ราคา Watchlist เป็นราคาปิดรายวันปรับแล้ว ไม่ใช่ราคาเรียลไทม์ ตรวจ `Price_AsOf` และเวลาของ quote ก่อนใช้งาน คะแนนและแผนซื้อเป็นกติกาเชิงเทคนิค ไม่ใช่ผลทดสอบย้อนหลังหรือการรับประกันกำไร

## ข้อมูลอัตโนมัติ

- `Update market data (free)`: daily ตามเวลาไทย 13:17 อังคาร–เสาร์ และ bootstrap 01:17, 07:17, 19:17 ทุกวัน ตารางเวลาไม่รับประกันว่ารันตรงนาที
- `Deploy and verify workspace`: หลังโค้ดบน main เปลี่ยน จะรัน tests เตรียมข้อมูลจริงชุดสำคัญ และตรวจเว็บด้วย Chromium จากนั้นเติมข้อมูลทั้งชุดต่อ
- `Validate dashboard`: ทดสอบโค้ดและ Streamlit AppTest เมื่อเปิด Pull Request โดยจำลองผู้ให้ข้อมูล
- `Public site diagnostic`: อ่านหน้าสาธารณะเพื่อช่วยวินิจฉัยการติดตั้ง ไม่ใช่การยืนยันว่าการใช้งานครบทุกหน้าผ่าน

ไฟล์ข้อมูลอยู่ใน GitHub Releases ชื่อ `dashboard-data-...` และตัวชี้ชุดพร้อมใช้งานอยู่บน branch `dashboard-data` ที่ `dashboard/latest.json` หน้าเว็บอ่าน summary และข้อมูลส่วนของหุ้นที่เลือก ไม่โหลดฐานข้อมูลทั้งหมดทุกครั้ง ส่วน `checkpoint.sqlite3` ใช้เก็บความคืบหน้าระหว่างรอบ collector

รายชื่อหลัก 4,900 ตัวไม่ได้แปลว่าข้อมูลทั้งหมดครบหรือสด งานอัปเดตที่สำเร็จอาจเป็นเพียงการบันทึกความคืบหน้า ดู `coverage`, `bootstrap_pending` และ `report` ในหน้าสถานะข้อมูล อย่ารันซ้ำถี่เมื่อถูกจำกัดคำขอ
