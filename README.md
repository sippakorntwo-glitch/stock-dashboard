แดชบอร์ดหุ้นและ ETF ภาษาไทย: https://my-stock-terminal.streamlit.app/

## การใช้งานแบบหน้าเดียว — v14

คลิกชื่อหุ้น ชื่อบริษัท หรือช่องใดก็ได้ในแถวของตารางหุ้นด้านบน แล้วกราฟและข้อมูลของหุ้นนั้นจะแสดงต่ออยู่ด้านล่างในหน้าเดียว ไม่ต้องเลือกมุมมองจากเมนูซ้าย ใช้ตัวเลือกแถวซ้ายสุดของตารางแทนการคลิกเซลล์ได้เช่นกัน

ลำดับในหน้า: ตารางและตัวกรอง → กราฟและแผนซื้อ / วิเคราะห์ 360° / คำนวณขนาดสถานะ → พื้นฐานและปันผล → ความเสี่ยง → เปรียบเทียบหลายตัว → สรุปอุตสาหกรรม → สถานะข้อมูล มีลิงก์ใต้ตารางสำหรับเลื่อนไปยังกราฟโดยไม่เปลี่ยนหน้า

ช่อง Ticker ทางซ้ายยังพิมพ์เองได้ และจะเปลี่ยนตามหุ้นที่คลิก ตัวกรอง การเรียงลำดับ การแบ่งหน้าตาราง และการอัปเดตข้อมูลไม่เปลี่ยนหุ้นที่เลือกเงียบ ๆ การเลือกหุ้นตัวใหม่จะตั้งคู่เปรียบเทียบกับ SPY; เมื่อเลือก SPY จะใช้ QQQ เป็นคู่เริ่มต้น ปรับรายชื่อเปรียบเทียบเองได้ 2–6 ตัว

หน้าเว็บแยกจำนวนรายชื่อออกจากจำนวนที่มีราคาจริง ช่องว่างคือยังไม่มีข้อมูล ไม่ใช่ศูนย์ ราคา Watchlist เป็นราคาปิดรายวันปรับแล้ว ไม่ใช่ราคาเรียลไทม์ ตรวจ `Price_AsOf` และเวลาของ quote ก่อนใช้งาน คะแนนและแผนซื้อเป็นกติกาเชิงเทคนิค ไม่ใช่ผลทดสอบย้อนหลังหรือการรับประกันกำไร

## ข้อมูลอัตโนมัติและการตรวจสอบ

- `Update market data (free)`: daily ตามเวลาไทย 13:17 อังคาร–เสาร์ และ bootstrap 01:17, 07:17, 19:17 ทุกวัน ตารางเวลาไม่รับประกันว่ารันตรงนาที
- `Deploy and verify workspace`: หลังโค้ดบน main เปลี่ยน จะรัน tests เตรียมข้อมูลจริงชุดสำคัญ และตรวจเว็บสาธารณะด้วย Chromium จากนั้นเติมข้อมูลทั้งชุดต่อ
- `Validate dashboard`: ทดสอบการเลือกหุ้นและ Streamlit AppTest แบบหน้าเดียว โดยห้ามเรียกผู้ให้ข้อมูลจริงใน unit/integration tests
- `Full browser verification`: เปิดเซิร์ฟเวอร์ทดสอบด้วยข้อมูลตลาดจริง คลิกเซลล์/แถวในตารางจริง แล้วตรวจกราฟและทุกส่วนของหน้าเดียว ผลบน localhost ไม่ใช่การยืนยันเว็บจริง
- `Public site diagnostic`: อ่านหน้าสาธารณะเพื่อช่วยวินิจฉัยการติดตั้ง ไม่ใช่การยืนยันว่าการใช้งานครบทุกส่วนผ่าน

ไฟล์ข้อมูลอยู่ใน GitHub Releases ชื่อ `dashboard-data-...` และตัวชี้ชุดพร้อมใช้งานอยู่บน branch `dashboard-data` ที่ `dashboard/latest.json` หน้าเว็บอ่าน summary และรายละเอียดเฉพาะหุ้นที่เลือกหรือใช้เปรียบเทียบ ไม่โหลดรายละเอียดทั้ง 4,900 ตัวทุกครั้ง ส่วน `checkpoint.sqlite3` ใช้เก็บความคืบหน้าระหว่างรอบ collector

รายชื่อหลัก 4,900 ตัวไม่ได้แปลว่าข้อมูลทั้งหมดครบหรือสด งานอัปเดตที่สำเร็จอาจเป็นเพียงการบันทึกความคืบหน้า ดู `coverage`, `bootstrap_pending` และ `report` ในส่วนสถานะข้อมูล อย่ารันซ้ำถี่เมื่อถูกจำกัดคำขอ

## v15: 500 แถว, Tooltip และช่วงกราฟเพิ่มเติม

ตารางแสดงหน้าละ 500 ตัว รักษาตัวกรอง การเรียง และการเลือกหุ้นแบบหน้าเดียว ชี้หัวคอลัมน์เพื่อดูคำอธิบาย; ตารางเกณฑ์/พื้นฐาน/วิเคราะห์/สถานะมี ⓘ ที่ชื่อแต่ละแถว พร้อมคำอธิบายที่กดอ่านบนมือถือได้ ไม่เปลี่ยนสูตรหรือคะแนนเดิม

กราฟเพิ่ม 1 วัน, 3 วัน, 5 ปี, 10 ปี และคงช่วงเดิม: วัน = วันซื้อขายล่าสุดที่มีข้อมูล ใช้แท่ง 5 นาทีในเวลาตลาดปกติ; เดือน/ปี = แท่งรายวัน ไม่ใช่แท่งละ 3 วัน แสดงช่วงจริงและคำเตือนเมื่อประวัติไม่ครบ ไม่สร้างข้อมูลให้หุ้นที่อายุน้อยกว่า 10 ปี

เลือกช่วงสั้น/ยาวพิเศษอาจดึง Yahoo เฉพาะหุ้นนั้นจากเซิร์ฟเวอร์ Streamlit: แคชอย่างน้อย 15 นาทีสำหรับ intraday และ 24 ชั่วโมงสำหรับระยะยาว คิวไม่เกิน 8 และไม่เกิน 60 คำขอต่อชั่วโมงต่อเซิร์ฟเวอร์ พักเมื่อผู้ให้ข้อมูลจำกัดคำขอ ไม่ใช่ราคาสตรีมสด การโหลดล้มเหลวคงข้อมูลเดิม ประวัติกราฟพิเศษแยกจากการให้คะแนนและไม่เผยแพร่กลับ GitHub ค่า DASHBOARD_ALLOW_LIVE_UPDATES ยังไม่ถูกเปิด ปิดคำขอกราฟเพิ่มเติมได้ด้วย DASHBOARD_ALLOW_CHART_REQUESTS=false ใน Streamlit Secrets ค่าเริ่มต้น true เพื่อรองรับช่วงที่ขอ

กราฟรักษาช่วงเวลาเมื่อปรับขนาดหน้าจอ และแสดง 10 ปีได้โดยไม่ติดข้อจำกัดความกว้างขั้นต่ำต่อแท่ง


## v16: ผลตอบแทนตามช่วงกราฟและตารางที่อ่านง่ายขึ้น

หัวกราฟเพิ่ม **ผลตอบแทนสะสม** ของช่วงที่เลือก เช่น 7 วัน หรือ 10 ปี แยกจากเปอร์เซ็นต์ของแท่งล่าสุด คำนวณ `(Close สุดท้าย / Close แรกภายในช่วงที่เลือก - 1) × 100` จากแท่งราคาปรับแล้วชุดเดียวกับกราฟ ไม่ใช้ประวัติ warm-up ก่อนช่วง ไม่บวกปันผลซ้ำ ไม่ใช่ CAGR และยังไม่หักค่าธรรมเนียมหรือภาษี ช่วงระหว่างวันใช้ Close ของแท่ง 5 นาทีแรกในวันซื้อขายแรกของช่วง ไม่ใช่ราคาปิดวันก่อน; แสดงราคาและวันเริ่ม/สิ้นสุดให้ตรวจได้ ผลตอบแทนนี้ติดตามปุ่มช่วงเวลา ไม่เปลี่ยนเมื่อเลื่อน/ซูมกราฟเอง

ข้อมูลไม่ครบสิบปีจะแสดง **ผลตอบแทนข้อมูลที่มี** และคำเตือน ไม่อ้างว่าเป็นผลสิบปีเต็ม เมื่อราคาไม่สมบูรณ์หรือมีน้อยกว่าสองแท่งแสดง — แทนการสมมติเป็นศูนย์

นำ Tooltip และไอคอน ⓘ ออกจากช่องตัวเลข หมวดหมู่ คำแปลผล คะแนน/เงื่อนไข และแหล่งข้อมูลในตารางอธิบายตามภาพ รวมทั้งหัวคอลัมน์ของตารางเหล่านี้ เหลือคำอธิบายเฉพาะชื่อเกณฑ์/ชื่อตัวชี้วัดที่จำเป็น ส่วนหัวคอลัมน์ในตารางรายชื่อหุ้น 500 ตัวและการเลือกหุ้นหน้าเดียวยังเหมือนเดิม ไม่เปลี่ยนสูตรให้คะแนน ราคา แหล่งข้อมูล หรือสิทธิการเข้าถึง
